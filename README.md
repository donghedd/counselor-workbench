# 辅导员工作台

一个**完全离线、单机运行**的高校辅导员班级管理工作台：把学生主表、毕业去向、寝室/外住、谈话跟进、劳动教育、学业警示等分散在 Excel 里的信息，汇总成一个可以点、可以筛、可以查的网页看板。

数据全部留在本机 `data/` 目录，程序只监听 `127.0.0.1`，**不联网、不上传、不依赖任何云服务**。

---

## 功能

| 模块 | 说明 |
|---|---|
| 全局总览 | 人数、去向分布、风险预警、材料缺失等 KPI，点数字直接跳到名单 |
| 班级 / 班委 | 按班级、职务聚合，班委看板 |
| 毕业去向 | 考研 / 保研 / 留学 / 就业 / 待定，点行看学生完整详情 |
| 寝室 / 外住 | 按楼栋楼层分组，外住审批与地址（地址自动打码） |
| 谈话跟进 | 谈话记录、问题类别、跟进状态，可在线新增 |
| 劳动教育 | 项目、参与学时、排班、考核材料 |
| **学业** | 培养方案解析、全校成绩分析、挂科/应修未修/学分缺口/学科交叉，自动生成学业警示与毕业警示 |
| 导入导出 | 导入 xlsx/csv 重建看板，导出脱敏版 HTML 与汇总 xlsx |
| 在线更新 | 侧栏显示当前版本，发现 GitHub 新 Release 时顶部提示，一键下载覆盖安装（数据不动） |

学业模块的口径（可自行调整）：

- **未获学分科目** = 截止目前应获而未获的科目；只有文化素质（含艺术类）、外语基础、外语拓展、学科交叉四类按「课程组还差多少学分」显示，其余一律列出具体课程名（挂科 / 该修未选 / 待修）
- 挂科：已完成学期成绩 <60 或不及格；**重修 / 补考 / 成绩替代通过后不再算挂科**
- 成绩替代、成绩认定（方案外）：按「替代课程号」归入培养方案对应课程，视为已修读
- 学科交叉 = 培养方案外课程中，除文化素质、体育、四史、外语及必修/专业类之外的课程
- 大四挂科显示「毕业警示」，大一~大三显示「留级警示」；累计学分不足按修读年限阈值另标
- 警示名单里的每名学生都可点「成绩跟进」登记补考/重修结果：标记通过后该课计入已得学分、挂科自动消除，原始成绩文件不动，随时可撤销

## 快速开始

### 方式一：安装包（推荐，像 QQ 一样装）

到 [Releases](../../releases) 下载 `辅导员工作台-vX.Y.Z-安装版.exe`，双击 → 一路「下一步」→ 装完自动创建桌面和开始菜单快捷方式，双击图标就能用。

- 双击图标打开的是**独立窗口**（无地址栏、无标签页，和 QQ 这类桌面软件一样），关窗即退出；
  窗口用系统自带的 WebView2 内核渲染（Win10 1803+ / Win11 默认内置），不需要额外装浏览器；
  万一该内核缺失，程序会自动退回 Edge 的独立窗口模式，再不行才用浏览器打开。
- 默认装在 `C:\Users\<用户名>\AppData\Local\Programs\辅导员工作台`，**不需要管理员权限**，安装过程中可以自己改路径。
- 卸载走「设置 → 应用 → 辅导员工作台」，或者在开始菜单里点「卸载」。卸载时会问一句要不要删学生数据，**默认保留**。
- 覆盖安装只更新程序文件，`data\`、`photos_src\`、`备份\` 不会被覆盖；看板会在下次启动时按新模板重新生成。
- 安装包没有数字签名，第一次运行 Windows 可能提示「Windows 已保护你的电脑」——点「更多信息 → 仍要运行」即可。

**关于更新**：装好以后不用再去 GitHub 手动下载。侧栏底部显示当前版本（如 `v2.1.0 · 检查更新`），
程序启动时会静默查一次最新 Release，有新版本就在页面顶部弹提示条，点「立即更新」会自动下载安装包、
关闭程序并覆盖安装——`data\`、`photos_src\`、`备份\` 一律保留。

更新源只需设置一次：点侧栏「检查更新」，按提示填 GitHub 仓库（`用户名/仓库名`，例如
`zhangsan/counselor-workbench`），保存在 `data/settings.json`。私有仓库需要额外填一个只读 token；
公开仓库留空即可。也可以把仓库直接写进程序目录的 `update.json`，随程序一起分发。

### 方式二：绿色版 zip

到 [Releases](../../releases) 下载 `辅导员工作台-vX.Y.Z-win64.zip`，解压到任意目录（路径别含特殊字符），双击 **`辅导员工作台.exe`**，会弹出一个独立窗口（无地址栏、无标签页，和普通软件一样），关窗即退出。

> 首次运行会自动生成空数据结构和看板，再通过页面上的「导入表格 / 导入成绩 / 导入培养方案」填入自己的数据。

### 方式三：源码运行

```bash
git clone <本仓库地址>
cd 辅导员工作台
python init_data.py        # 初始化空数据目录（仅表头模板）
python build.py            # 生成 dashboard.html
python server.py           # 启动本地服务 http://127.0.0.1:8787
```

要求 Python 3.9+，只用标准库；`openpyxl` 为可选项（装了才会额外导出汇总 xlsx）。

Windows 下也可以直接双击 `启动编辑模式.bat`。

## 目录结构

```
├─ launcher.py          启动入口（exe 打包目标）
├─ server.py            本地 HTTP 服务 + 各导入/保存接口（仅 127.0.0.1）
├─ build.py             data/*.csv → dashboard.html / 脱敏版 / 汇总 xlsx
├─ academic.py          培养方案解析 + 成绩分析 + 学业警示（核心业务逻辑）
├─ xlsx_io.py           零依赖 xlsx 读写（不装 openpyxl 也能读）
├─ db_sync.py           CSV ↔ SQLite 同步
├─ app_paths.py         源码运行 / exe 运行的路径解析
├─ init_data.py         首次运行初始化 data/（复制空表结构）
├─ version.py           版本号唯一来源（改版本只改这里）
├─ updater.py           GitHub Release 检查 + 一键下载安装
├─ update.json          更新源配置（仓库 owner/name，可留空）
├─ template.html        前端模板（唯一不含数据的版本）
├─ data_template/       空表结构（只有表头，可安全提交）
├─ make_release.py      一键打发布 zip
└─ installer/           安装包工程（Inno Setup 脚本 + 图标资源）
```

安装包怎么来的：

```bash
python make_release.py                 # 先生成 dist\辅导员工作台-v<版本>\（安装包的内容源）
python installer\make_assets.py        # 图标 / 向导图（改图标后重跑）
installer\编译安装包.bat                # 读 version.py → 调 ISCC 编译安装包，并另存一份 ASCII 名
```

需要装 [Inno Setup 6](https://jrsoftware.org/isdl.php)（免费）；脚本里 `PrivilegesRequired=lowest`，装到当前用户目录，不弹 UAC。

`dashboard.html` 是生成物，`.gitignore` 里已排除；`data/`、`photos_src/` 等含个人信息，同样不入库。

## 隐私与安全

- 程序只绑定 `127.0.0.1`，局域网其它机器访问不到；关闭窗口即停止服务。
- 仓库里**不包含任何真实学生数据**：`data/`、`photos_src/`、`备份/`、`*.db`、成绩/培养方案 xlsx 全部在 `.gitignore` 中。
- 分享前请使用页面导出的「脱敏版 HTML」：姓名首字+`*`、学号后四位、手机号中间四位打码，照片不打包。
- 若确实要备份到云端，请用**私有仓库**并只存代码，数据单独加密备份。

## 已知限制

- 成绩表中的「计划学年学期 / 课程性质 / 学分」是从成绩记录反推的，方案里从未开过的课可能显示 `—`。
- 培养方案 xlsx 为合并单元格版式，解析依赖教务导出格式；格式大改时需要调整 `academic.py` 的解析逻辑。
- 仅适配 Windows（启动器为 exe + bat），macOS / Linux 可用 `python server.py` 运行。

## 许可

仅用于个人/校内班级管理辅助，请遵守所在学校的个人信息管理规定。
